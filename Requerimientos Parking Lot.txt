Requerimientos Parking Lot
Requerimientos de usuario
REQ-USR-1: El sistema debe tener solo 3 perfiles de usuario en su parametrización inicial: Administrador, operador, usuario.
REQ-USR-2: El sistema debe permitir solo al administrador y a los operadores crear nuevos usuarios, usando como parámetro de entrada y registro los siguientes datos: tipo de documento (obligatorio), numero de documento (obligatorio), nombre completo (obligatorio), dirección de correo electrónico (obligatorio), número de celular (obligatorio), fotografía (opcional), tipo de usuario (administrador, operador o usuario). El sistema asignará un código único y autoincremental al momento del registro y este identificará de manera única al usuario.
REQ-USR-3: El sistema debe permitir solo al administrador actualizar el estado de un usuario de activo a inactivo. 
REQ-USR-4: El sistema debe permitir a cada usuario actualizar sus datos personales y al hacerlo se le debe enviar una notificación al administrador.
REQ-USR-5: El sistema debe permitir al administrador actualizar los datos de los usuarios.
REQ-USR-6: El sistema debe permitir al administrador o al operador asignar un vehículo de propiedad. 
REQ-USR-7: El sistema debe permitir al administrador y al operador acceder al sistema usando su número de documento y contraseña.
REQ-USR-8: El sistema debe permitir a los usuarios acceder al sistema solo con su número de documento.
Requerimientos de vehículo
REQ-CAR-1: El sistema debe permitir al administrador o al operador crear un vehículo usando como datos de registro: Placa, color, marca y modelo.
REQ-CAR-2: El sistema debe permitir solo al administrador actualizar la información de un vehículo.
REQ-CAR-3: El sistema debe permitir solo al administrador asignar un vehículo a otro usuario.
REQ-CAR-4: El sistema debe permitir al administrador o al operador crear una tabla de restricciones de placa por día para evitar el ingreso de un vehículo que cumpla con el criterio de restricciones (pico y placa).
Requerimientos de accesos y salidas
REQ-INEX-1: El sistema debe permitir al operador o al administrador registrar la entrada de un vehículo en la puerta de cualquiera de los accesos, usando como parámetro de entrada, la puerta de acceso, la placa del vehículo, la fecha y la hora de entrada.
REQ-INEX-2: El sistema debe permitir al operador o al administrador registrar la salida de un vehículo en la puerta de cualquiera de los accesos, usando como parámetro de entrada, la puerta de acceso, la placa del vehículo, la fecha y la hora de entrada.
REQ-INEX-3: El sistema debe iniciar un conteo de tiempo una vez un vehículo ingrese al parqueadero, y debe finalizar el conteo una vez salga del parqueadero. El lapso de tiempo debe registrarse en el sistema con fecha y hora. 
REQ-INEX-4: El sistema debe negar el acceso o evitar el registro de entrada de un vehículo cuya placa incumpla la tabla de restricciones por día (pico y placa).
Requerimientos de incidencias
REQ-INCD-1: El sistema debe permitir registrar incidencias ocurridas dentro del parqueadero, y estas incluyen: Rayones, choques, atropellamientos, golpes contra muros. Las incidencias deben ser registradas con un código único autogenerado por el sistema, el vehículo afectado, la fecha, hora y el tipo de incidencia.
Requerimientos de celdas de parqueo
REQ-CLD-01: El sistema debe permitir al operador, al administrador y a los usuarios visualizar todas las celdas de parqueos disponibles o ocupadas por área, piso o nivel. Cada celda debe tener un estado (ocupado o disponible), un código único, el tipo de celda (si es de moto o de carro) y el área al que pertenece.
REQ-CLD-02: El sistema debe permitir visualizar todas las celdas disponibles y ocupadas a los usuarios por medio de una interfaz individual accesible por medio de su cuenta.
REQ-CLD-03: El sistema debe permitir actualizar el estado de cada celda de ocupado a disponible o de disponible a ocupado en cualquier momento. Cuando está ocupado se debe asociar un vehículo que ocupa la celda.
Requerimientos de reporte y consulta
REQ-REP-01: El sistema debe permitir solo al administrador consultar y generar listado de todos los usuarios del sistema con todos sus datos.
REQ-REP-02: El sistema debe permitir solo al administrador consultar y generar listado de todos los vehículos registrados en el sistema con todos sus datos junto con el usuario (propietario) asociado.
REQ-REP-03:  El sistema debe permitir solo al administrador listar todos las entradas al parqueadero con su fecha, hora y vehículo
REQ-REP-04:  El sistema debe permitir solo al administrador listar todos las salidas al parqueadero con su fecha, hora y vehículo
REQ-REP-05:  El sistema debe permitir solo al administrador listar todos las incidencias que se generaron dentro del parqueadero.
REQ-REP-06:  El sistema debe permitir solo al administrador listar el total de vehículos que no ingresarán en un determinado día por restricciones de pico y placa.
REQ-REP-07:  El sistema debe permitir solo al administrador listar el total de celdas ocupadas por día determinado.
REQ-REP-08:  El sistema debe permitir solo al administrador listar las celdas más usadas en un lapso de tiempo.
REQ-REP-09:  El sistema debe permitir solo al administrador listar los vehículos que mas usan el parqueadero.
REQ-REP-10:  El sistema debe permitir solo al administrador listar las horas y días que mas se ocupa en su totalidad el parqueadero.
